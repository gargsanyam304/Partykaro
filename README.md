# Partykaro

Frontend marketing site for **Partykaro** — a celebration planning service that arranges birthday parties and other events at hotels and restaurants, with a path to onboard dealers and venue partners.

## Stack

- React + TypeScript
- Vite
- React Router

## Run locally

```bash
npm install
npm run dev
```

Then open the URL shown in the terminal (usually `http://localhost:5173`).

## Pages

- `/` — Home: hero, occasions, how it works, venues, packages, gallery, partners teaser, FAQ
- `/book` — Celebration brief form (frontend-only; shows a success state)
- `/partners` — Dealer / venue partner onboarding form

## Build

```bash
npm run build
npm run preview
```
